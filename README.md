# Jobsdle

A daily guessing game: name the monthly change in U.S. nonfarm payrolls (2000–2026), with unemployment, CPI and other figures from the same BLS release revealed as hints.

- `index.html` is the whole game, with the data built in.
- `build.py` turns BLS API responses into the data array.

Data: U.S. Bureau of Labor Statistics, seasonally adjusted, current revised estimates.
